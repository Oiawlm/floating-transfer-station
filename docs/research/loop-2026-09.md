## 2026-09-25(整点接力首夜,切片 1:采集去重 + B-006,1.9.1)

**方向与决策**

整点接力机制首夜(23:00–09:00,锁 + checkpoint + 整点兜底触发)。直接选取候选池双 lane 均列第 1 的"采集去重 + 微信复制图片偶发双份修复"(B-006),未再重复发散提案——候选池高优先项可直接选用。根因定位:微信等来源一次复制分多步写剪贴板,产生多个**不同序号**的通知,原有按 `GetClipboardSequenceNumber` 的去重无法合并;修复取内容级指纹而非继续纠缠序号。

**实现**

- Core 新增 `CaptureDeduplicationGate`(只记最近一条成功采集,默认 5 秒窗口,时钟可注入)与 `CapturedContentFingerprint`(文本 = 整理插件处理后全文 SHA-256;图片 = 规范化后 PNG 解码像素 + 尺寸的 SHA-256——按像素而非编码字节,位图与文件路径等不同表示之间可互认;解码失败返回 null 即放弃去重,绝不影响采集)。
- `ClipboardCaptureService` 注入可选去重门(默认 null 保持旧行为,既有对抗测试锁定"无门不抑制"契约):检查与记录都在 `BoardOperationGate` 内串行,消除双通知竞态;抑制时不入库、删除已规范化文件并提示"与最近收集的内容相同,未重复收集。";批量多条导入与外部拖入永不因重复被抑制;保存失败不记指纹。
- Mac 端遵守暂停边界:共享 Core 已具备能力,采集接线待恢复;Mac 测试(36 项)与 Apple Silicon CI 全绿。
