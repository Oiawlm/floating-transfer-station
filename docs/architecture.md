# 架构说明

悬浮中转站是一个 .NET 10 WPF 桌面应用。代码按“状态与模型、业务服务、窗口交互、持久化与安装”分层，但没有为了分层引入额外框架。

## 主要责任

- `Models/`：分类、内容项、剪贴板快照、外部拖入载荷和窗口设置等数据结构。
- `Services/`：剪贴板采集、图片规范化、板内容变更、原子保存、拖放载荷、窗口状态机和生命周期。
- `ViewModels/`：分类与主窗口的可绑定状态。
- `Views/`：WPF 视觉树、指针交互、选择删除、拖放、动画和窗口生命周期。
- `Views/MainWindow.CategoryEditing.cs`：分类名称编辑、中文输入法组合、提交与设置保存；保持与主窗口同一 partial 类型。
- `installer/`：安装目录、数据目录迁移、自启登记和安全卸载边界。
- `tests/`：服务级回归、真实 WPF 交互回归、安装/发布元数据和对抗性路径。

`MainWindowInteractionTests` 按分类编辑、选择删除、拖放、视觉与生命周期分文件；`LifecycleTests` 按运行时、安装器、发布资料和发布准备检查分文件。它们保留原类名，`run-adversarial.ps1` 的定向选集不依赖文件名。

## 核心数据流

1. 剪贴板通知或外部拖放被读取为候选载荷。
2. 图片先规范化为应用管理的本地副本；文字保留实际文本。
3. `BoardService` 和相关变更服务按分类、置顶区和顺序规则生成新快照。
4. `LocalStore` 使用临时文件和原子替换保存 `board.json`；失败时界面操作恢复到原状态。
5. 界面只在保存成功后保留变更，并通过通用 Windows 数据格式对外拖出。

剪贴板在通知入口冻结目标分类。生产读取器提供系统序号，使同序号通知在分配载荷前合并；不同通知仍尽早读取，并按预留顺序处理。重复、不可读或取消的通知保留前驱依赖，不能让后来的内容越过尚未完成的图片处理。

ClipboardPayloadReader 在同一个 IDataObject 上先检查历史排除标记，再读取图片、文件和文字；带有禁止记录标记的内容不会进入持久化。ClipboardCaptureService 最多接纳 16 个在途操作，已读取的载荷估算总量最多 256 MiB；超限不消费该次序号，提示用户稍后重新复制。这个预算不等于进程总内存上限。

文件列表先逐个归一化，保留可用图片的来源顺序，再在操作门内一次提交；提交失败撤销本批插入并清理副本。ImageInputLimits 限制每个编码输入或源文件为 64 MiB、6,400 万像素，归一化应用 EXIF 方向后保存原分辨率 PNG。首帧用途只解码一帧，静态外拖在预检时拒绝多帧文件。

ImageSharp 单组图像缓冲分配另有 512 MiB 上限，用于约束帧矩形等不完全体现在画布像素数中的分配；它也不是整个进程的内存上限。读取器会核对获取载荷前后的系统序号，变化时走已有重试流程，防止把旧载荷标记成新序号。

ManagedImagePath 检查管理图片目录以及其内部路径组件，拒绝已有 reparse point；配置父目录的链接仍可使用。非法图片路径逐条过滤，不阻断其余板数据的启动恢复。这是路径与文件操作前的校验，不是针对同权限进程恶意并发换链的隔离机制。

删除入口在保存期间固定作用范围并阻止重入；移动操作进入共享操作门后重新处理失效 ID。外部拖入栏和普通收起同步状态机、ViewModel 与窗口位置。

开机自启由安装器的 `[Registry]` 项统一登记到当前安装目录。`AppLifecycleService` 只管理单实例所有权，应用启动不会修改自启项。

## 不能随意改变的契约

新安装器登记当前程序安装目录，卸载器先确认自身归属；清理失败保留数据目录登记。缺少归属登记的旧安装先原地更新，再允许变更程序目录。修复前已遗留的旧卸载器仍属于未受保护的历史状态。

- 置顶项始终位于普通项之前，两个区域分别排序。
- 批量跨分类移动保持批内顺序和置顶状态，失败时整批回滚。
- 删除、清空、移动和置顶在保存失败时不能留下部分结果。
- 图片或文字拖出不会删除源卡片。
- 卸载只能递归删除应用登记且能证明由应用管理的数据目录。
- 递归删除只针对规范化后的 `Data`；它的父目录仅尝试空目录删除。安装清理行为由 `scripts/test-installer-cleanup.ps1` 提取真实 Pascal 函数，在隔离合成目录中验证。
- 保存后的选择恢复必须核对当前分类，并尊重用户在保存期间主动取消选择的操作。
- 中文输入法组合期间不能逐键写回或截断分类名称。

修改这些契约前请先开 Issue，并同时考虑调用方、持久化、升级、安装器、测试和公开文档。
