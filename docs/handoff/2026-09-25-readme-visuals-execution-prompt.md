## 第一性原理（本次所有取舍的判断基准）

README 不是文档，是陌生读者的**采纳决策链**：3 秒内明白这是什么 → 敢不敢装 → 能不能解决我的问题 → 会不会用，任何一环失败读者就离开。由此推出四条基准：

1. **文字承载契约，图承载证明**。路径、键位、版本号、限制、命令是可复制、可校验的契约，只能用文字；「声称的行为真的会发生」（复制即入库、悬停展开、拖出去交付）只能用图证明。二者不可互换：用图承载契约会失真且过期，用文字承载行为读者只能选择「相信」。
2. **时间本身是不是信息？** 卖点在状态随时间变化（拖放、收起/展开、自动保存）→ 动图；卖点在静止形态（面板结构、设置窗口）→ 静态图；两者都不是 → 不加图。
3. **一条资产只证明一个声明**。Hero 负责建立整体心智模型（一个完整闭环），功能图一律近景单动作；一个连贯的批量整理序列（多选→置顶→移动）视为一个声明。取景互不重复。
4. **图是负债**。UI 一变图就过期：数量克制（预算见下）、同一录制会话一次产出、留下可再生的脚本与步骤说明。

**明确不加图的章节**（推导见调研材料一）：平台/版本引用块、几个常用操作（键位表）、Windows 数据和卸载、Mac 版（无 Mac 画面，放 Windows 图是误导；且 Mac 开发已暂停）、当前限制、接下来准备做什么（尚无真实画面）、本地开发 / 参与贡献 / 许可证（命令与流程）。「图片容错」「本地保存」两条 bullet 没有稳定可见的界面差异，也不加。

## 制作管线（要点；完整参数与风险清单见调研材料二）

**环境事实（规划窗口 2026-09-25 已核实）**：Windows 11，主屏 2560×1600 物理分辨率、系统缩放 150%（所有录制/裁剪坐标用物理像素，警惕 DPI 虚拟化偏移）；ffmpeg 已装且在 PATH 中；gifsicle 未装（`winget install gifsicle`，装不上不影响主线：改用 `palettegen=max_colors=128` + `bayer` 抖动）；ZCode 有官方 **computer-use 技能**负责「表演」（悬停/拖放/点击/打字）与画面观察。

0. **录制环境固定（一次性，收尾恢复）**：退出正在运行的真实应用实例（剪贴板是系统级共享的，否则演示复制会被真实实例采集进真实数据）；告知用户录制期间剪贴板内容会被覆盖；开启勿扰/关闭通知；隐藏桌面图标、退出聊天软件；固定单显示器、缩放不变、关闭 HDR/夜间模式。记录所有临时改动。
1. **隔离启动**：种子数据目录用**不含用户名的中性路径且在仓库外**（如 `D:\fts-demo\`，确认 `git status` 不跟踪）。PowerShell 设置 `FTS_PREVIEW_DATA_DIR` 与 `FTS_PREVIEW_THEME`（统一主题，Plan 定深/浅）后启动 `%LocalAppData%\Programs\悬浮中转站\` 下的应用。预览模式有独立互斥体与独立数据目录；**绝不动真实用户数据**，收尾核对真实数据目录修改时间未变。
2. **种子数据**：分类用 README 默认名（图片、文本2、待分类、复盘）；每分类 3–6 张中性卡片（短示例文字 + 脚本生成的纯色/渐变占位图，放 `D:\fts-demo\assets\`）；部分卡片置顶；`reviews/` 预置 ≥3 天 Markdown；固定窗口位置并记录物理坐标。**每条资产开拍前用干净种子副本重启**预览实例；重录同一段文案必须间隔 >5 秒或换文案（产品有 5 秒去重规则）。
3. **录制**：computer-use 表演 + ffmpeg `gdigrab` 固定区域（hero 为面板 + 左侧相邻空间给目标窗口的横幅区；功能图只录面板有效交互区，**只缩不放**，物理宽度不足时扩大裁剪区而不是放大）。用 computer-use 读取/量取面板物理像素矩形后填入参数。`-draw_mouse` 显式声明（拖放/悬停类需要光标入镜；gdigrab 光标发糊先做 10 秒 ddagrab 对比冒烟再切换）。`-t` 固定时长 + `-progress pipe:1` 握手后开始表演。**FFV1 无损中间文件**写 `artifacts/readme-media/`（先 `git check-ignore` 确认不入库、确认所在盘余量 ≥20GB；FFV1 中间文件很大，每完成一条立即删 raw，收尾删整个目录）。
4. **转换**：`trim` 砍手势前后死时间 → `fps`（hero 12–15、其余 10–12、05 ≥12）→ `scale=只缩不放:flags=lanczos` → 两遍 `palettegen(stats_mode=diff)` + `paletteuse(diff_mode=rectangle)` + `-gifflags +transdiff -loop 0`；体积仍超标再 `gifsicle -O3 --lossy`。静态 PNG 量化压进预算，仍超标可改 WebP（GitHub 支持）。最小可用命令集：

```powershell
# 录制（X/Y/W/H 为物理像素，T 秒；先 artifacts\readme-media\）
ffmpeg -y -f gdigrab -framerate 15 -draw_mouse 1 -offset_x X -offset_y Y -video_size WxH `
  -i desktop -c:v ffv1 -pix_fmt bgr0 -t T artifacts\readme-media\raw-NN.mkv
# 调色板（S/E 为秒；fps/scale 按资产分档替换）
ffmpeg -y -i raw-NN.mkv -vf "trim=start=S:end=E,setpts=PTS-STARTPTS,fps=12,scale=520:-2:flags=lanczos,palettegen=max_colors=256:stats_mode=diff" -frames:v 1 -update 1 palette.png
ffmpeg -y -i raw-NN.mkv -i palette.png -filter_complex "[0:v]trim=start=S:end=E,setpts=PTS-STARTPTS,fps=12,scale=520:-2:flags=lanczos[x];[x][1:v]paletteuse=dither=sierra2_4a:diff_mode=rectangle" -gifflags +transdiff -loop 0 docs\images\NN-name.gif
# 断言
ffprobe -v error -select_streams v:0 -count_frames -show_entries stream=width,height,avg_frame_rate,nb_read_frames raw-NN.mkv
```

5. **断言与人工核看**：掉帧分级判断——先看动作完整性，缺关键帧才重录，单条最多重录 2 次，之后降分辨率或换 ddagrab 并记录取舍。核对宽高/帧率/体积在预算内（超了回滤镜链调参，不重录）。逐帧抽查隐私清单：用户名与真实路径、头像、通知横幅、任务栏、最近文件、浏览器标签标题、输入法候选窗。光标轨迹自然、首尾尽量回环、05 未提速。
6. **可复现**：录制坐标、命令、种子构造固化进 `docs/images/README.md` 的再生步骤；`docs/README.md` 索引加一行指向它。

## 执行方式

1. **Plan 模式**，依次过四道关卡后产出实施计划（资产清单定稿 + 每条内容脚本细化 + 验证方式）：
   - **第 0 步 · 可行性闸门**：`git rev-parse --show-toplevel` / `git remote -v` / `git status` 确认是本仓库克隆、在 main、能看到四份未跟踪材料（路径含空格，命令全部加引号）；读 `scripts/check-repo-hygiene.ps1` 并往任务分支**试提交一个 1KB 假二进制文件**确认不被拦（之后撤掉）；核验安装版 exe 文件版本与 main `version.txt` 一致（不一致先停下问用户）；`git check-ignore artifacts/readme-media`。
   - **环境核查**：ffmpeg `-version`、gifsicle、computer-use 技能可用性、winget 可用性。
   - **行为冒烟（硬关卡，结论写回资产表脚本）**：逐项实测——复制后卡片入默认分类（指针先移入展开；内容到达不触发展开）；外部拖入悬停分类的真实反馈形态；复盘停手有无可见保存反馈；记事本/浏览器是否接受文字/图片拖放；预览实例剪贴板自动采集是否开启；computer-use 能否完成跨窗口拖放与 250ms 级悬停节奏。任一项不成立就地改脚本或降级该资产，并记录。
   - **决策点（请用户拍板）**：①「不提交本机截图」红线豁免确认（留原话）；② P2 取舍：08/10/11 做哪些，09 默认不做；③ 统一主题深色还是浅色（另一种出 10 号对比图）；④ 要不要 shields.io 徽章行（属「文字不动」的例外，需显式同意，默认不加）；⑤ 发行豁免确认；⑥ PR 合并方式（默认用户合并）；⑦ 录制时段（用户避让键鼠 + 知悉剪贴板被覆盖 + 退出真实实例）；⑧ hero 放引用块前还是后。
2. **批准后执行**：按阶段提交——① 四份材料脱敏后入库并登记索引；② P0 四条资产 + README 插入；③ P1 三条；④ P2（若批准）。每阶段：一次录制会话产多条素材 → 转换与断言 → 插入 README → 本地预览（含列表结构核对）→ 提交。computer-use 连续 2 次无法复现同一动作即判定工具能力不足：停止自动录制，改为请用户手动演示录制、或该资产降级为静态图/删除，并在 PR 说明。
3. **收尾**：建 PR、盯 CI 到绿；向用户展示 GitHub 渲染链接与资产清单；PR 描述写明：Mac 无回归说明、红线豁免原话、质量门豁免理由、预算执行情况；恢复所有临时系统改动；清理 `artifacts/readme-media/`；再生步骤落进 `docs/images/README.md`。
4. 任何拿不准的决策点停下来问用户；录制失败先诊断根因再重试，不无限重录。
