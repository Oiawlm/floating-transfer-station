# 跨窗口交接材料

本目录存放跨窗口（跨会话）任务的交接提示词：当一个规划、调研或执行窗口需要把工作移交给新窗口继续时，把自包含的交接文档放在这里，并让新窗口以该文档全文作为首条消息启动。

交接文档应包含的要素：

- **背景**：仓库位置、前序窗口完成了什么、材料是否已提交。
- **必读输入**：按优先级排列的文档与代码清单（`AGENTS.md` 永远最高）。
- **目标**：一句话可核对的总目标与分项产出。
- **执行方式**：推荐的节奏（如先 Plan 后执行）、阶段划分与决策点。
- **验证方式**：质量门命令、需要自动回归的范围、UI 证据要求。
- **边界**：不可改变的红线、不动的工作区文件、需要用户决策的事项。
