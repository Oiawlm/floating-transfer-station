## 0. 判断基准（第一性原理，全程适用）

1. **文字承载契约，图承载证明**。对 `README.md` 的改动仅限图片引用、图注（一行斜体，普通资产 ≤25 字、02 号标注图 ≤40 字）、alt、加粗定位行；版本号、下载表、路径、键位一个字不动；不在 Markdown 列表中间插图；引用宽 ≤ 源宽。
2. **已完成的证明立即交付**。四条已验收资产（02/06/07/08）先行插入、提交、推送、开 PR——不被未完成的 10/11 阻塞。
3. **人只做只有人能做的事**（真实键鼠演示、最终肉眼验收、PR 合并），其余全部由代理自动化；边界写进对照表。
4. **图是负债**。数量克制、单项预算硬约束（见 §2 表）、留下可再生的脚本与步骤（`docs/images/README.md`）。
5. **免费算力默认外包**。自包含子任务（diff 文字层评审批判、文案变体、CHANGELOG 措辞、本文档完备性复查）默认派 wbx，并行 2 份择优；GUI 操作、ffmpeg 实跑、git/PR、隐私帧核看绝不外包。先 `doctor`，连续 ≥2 次失败即收回自做并如实告知。
6. **以官方文档与现场实测为准，不凭记忆编造**。工具行为（computer-use API、ffmpeg 滤镜、PowerShell 语义）先查你内置的官方技能文档（computer-use 技能、wb-bridge 技能、zcode-guide 插件）或现场试跑；联网核实时效性事实；仓库坐标/进程/窗口等一切状态以现场重查为准，不盲信本文数字。

## 6. 录制配方与已踩的坑（上一窗口实测结论，直接复用）

1. 主屏 2560×1600 物理、150% 缩放；一切坐标用物理像素；展开态面板 `[1843,135,717,1260]`（种子 settings 下），收起条**位置随默认分类行变化**（四行：图片 135/复盘 450/文本2 765/待分类 1080，每行高 315）——**每次动作前用 computer-use AX 实测 bounds，不盲信常数**。
2. ffmpeg `gdigrab` 区域录制 25fps 零掉帧；FFV1 中间文件写 `artifacts\readme-media\`；**gdigrab 软件光标恒画普通箭头**（光标形态不是拖拽证据，拖拽幽灵才是）。
3. 编码：两遍 `palettegen(max_colors=256:stats_mode=diff:reserve_transparent=0)` + `paletteuse(dither=sierra2_4a:diff_mode=rectangle)` + `-gifflags +transdiff -loop 0`；hero 缩 730、功能图缩 600；05 类节奏资产禁 `setpts`/缩时长，ffprobe 断言时长偏差 <5%。
4. SendInput 的 INPUT 结构体在 x64 必须补齐填充（`act.ps1` 已修）；PowerShell 方法名大小写不敏感（避免 `KeyUp`/`Up` 撞名，已改名 CtrlDown/CtrlUp）。
5. `Ctrl+单击`在面板内选中可靠（`act.ps1 -Ctrl`）；**对资源管理器的 Shift 注入无效、Ctrl 多选跨次残留**——先点空白清选中；合成多选+复制不稳（11 的 4 次失败根因）。
6. 打字用 `type-unicode.ps1`（KEYEVENTF_UNICODE 绕过输入法候选窗）；向真实窗口发按键前先确认前台正确。
7. PowerShell 5.1 把无 BOM 脚本当 ANSI：**脚本内不写中文字面量**（中文放 UTF-8 附属文件或运行时推导路径）。
8. 时序敏感序列写成**单脚本**（参考 `seq05.ps1`：一次进程、精确 sleep）；逐命令 spawn 每次约漂移 1.3s。
9. 资源管理器窗口会被系统/用户挪动——每条资产开拍前重新定位并实测文件 ListItem 坐标。
10. 每条资产开拍前：优雅关预览实例（`close-app.ps1 -ProcessId <pid>`）→ `D:\fts-demo\reset-working.ps1` → 重启；重录同一文案间隔 >5s（产品去重规则）。
11. 浏览器（Edge 本地页 `file:///D:/fts-demo/drop-target.html`）接受文字拖放；Win11 新记事本**拒收** OLE 文字拖放——演示目标一律用浏览器。
