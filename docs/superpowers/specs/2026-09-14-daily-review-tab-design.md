# 文本1每日复盘标签设计

## 目标

把现有 `BoardCategory.Reference`（“文本1”）改为按天书写复盘的入口。首次启用时清空该分类已有卡片，保留其他三个分类；复盘内容独立保存为本地 Markdown 文件，Windows 和 Mac 使用一致的保存与同步语义。

## 用户行为

- 标签默认显示“复盘”，仍可双击或按 `F2` 改名。
- 展开复盘标签后显示今天的多行 Markdown 编辑器、上一天/下一天按钮和历史日期列表。
- 输入停止约 700ms 自动保存；切换日期、切换标签和退出前等待保存。
- 空白内容删除当天文件；未来日期不可进入。
- 文件由 Obsidian 或其他编辑器外部修改时，编辑器无本地未保存内容则自动刷新；有未保存内容则提供保留本地、载入文件、三方合并。
- 复盘标签不改变剪贴板默认收集目标，不接受板卡拖放，也不参与板卡移动。

## 数据与迁移

复盘文件位于应用数据目录 `reviews/yyyy-MM-dd.md`，UTF-8 无 BOM，不写入 front matter 或模板。日期使用系统本地日期。`WindowSettings` 增加迁移版本字段；首次版本迁移清空 `Reference` 卡片、将名称设置为“复盘”并写入版本。迁移失败时不启用可写编辑器，并使用现有原子保存和备份语义恢复。

共享 Core 增加 `IDailyReviewStore`、`DailyReviewDocument`、文件变更事件和三方合并器。`LocalStore` 复用 `AtomicTextWriter`，每个文件串行写入。监听目录时合并重复事件，自身写入通过内容指纹抑制；监听错误触发全量重扫。

三方合并以最近一次共同内容为基线。单方修改直接采用该方；双方修改同一行时写入标准冲突标记，并保持编辑器 dirty，等待用户整理。

## 平台实现

Windows WPF 和 Mac Avalonia 各自使用原生多行 TextBox。编辑器获得焦点时，文本编辑快捷键优先于板卡快捷键。窗口关闭流程先停止监听并等待复盘保存，再执行现有板卡和设置保存。

## 验收

覆盖旧数据迁移、复盘文件读写与空文件删除、日期切换、自动保存、外部同步与冲突、剪贴板/拖放隔离、关闭等待，以及 Windows/Mac 的格式验证、Release 测试和严格构建。
