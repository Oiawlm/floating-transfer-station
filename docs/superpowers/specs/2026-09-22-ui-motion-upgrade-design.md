# 界面与动效升级设计

## 目标

以 Windows 11 Fluent 为设计基线，统一两端视觉与动效：颜色、圆角、时长、缓动、间距收敛为共享 Core 中的单一数值源（DesignTokens），WPF 与 Avalonia 各自渲染；悬停、显隐、选中、置顶、删除、收起等交互全部获得符合微软官方时长与曲线的过渡；深色模式跟随系统亮暗；图标线宽与端点风格统一；窗口材质（Mica）先做小样验证，通过并经用户确认后才全量实施。默认不引入第三方 UI 依赖。

## 用户行为

- 悬停、按压、选中、置顶、删除等操作获得 83–250ms 的即时视觉过渡；所有动效可中断、不阻断命中测试，动画不被用来传达唯一信息。
- 面板收起从硬切换变为约 200ms 的加速出场（内容向贴边轨道方向淡出位移）；快速展开/收起往复不闪烁、不截断内容。
- 新剪贴板条目以 30–50ms 交错入场；拖放插入位置指示器带淡入下滑入场。
- 深浅色跟随系统亮暗自动切换，无需手动设置。
- 系统「减弱动效」开启时，所有动效退化为 83ms 纯淡入或立即定格终值。

## 数据与迁移

- 不改变任何持久化契约：`board.json`、`settings.json`、`reviews/*.md` 结构不变；置顶分区、批量顺序、拖放源数据、安全卸载边界不变。
- `PanelStateMachine` 语义不变：60ms 悬停意图确认、250ms 收起延时、外部拖入栏行为保持；「收起视觉交接」防闪烁机制保留，收起动画在几何交接之前完成视觉出场。
- 共享 Core 新增 `DesignTokens` 常量类（颜色、时长三档、缓动曲线参数、圆角、间距），两端引用同一组数值；WPF 资源字典与 Mac 常量的值必须等于该来源，由跨端测试锁定。
- 色板定稿：两端统一采用现有 Windows 强调紫 `#6D5DFB` 及其派生色族（选中卡片、活动分类、悬停、拖放目标层）；Mac 端放弃青绿 `#327A72`。
- 删除反馈动画不改变删除管线：删除命令恰好执行一次、批量顺序不变；动画仅将视觉呈现延迟 ≤120ms，期间任何新交互立即跳过动画直接执行。

## 平台实现

- Windows：样式层引入 VisualStateManager + VisualTransition 承载 hover 与状态过渡；代码动画沿用 BeginAnimation；动画常量集中并取值于 DesignTokens。深色模式采用手工双套资源字典 + `WM_SETTINGCHANGE` 跟随系统，不引入 .NET 内置 Fluent 主题（规避设计器白屏与控件风格混入）。材质小样通过 `DwmSetWindowAttribute`（`DWMWA_SYSTEMBACKDROP_TYPE` 等）验证弃用 `AllowsTransparency` 的窗口壳变体；与分层窗口冲突且无法修复则保留现状并以阴影分层替代，结论如实写入文档。
- Mac：同一组 token 落地为主题化资源与常量，`RequestedThemeVariant` 跟随系统；动效用 Avalonia 原生 Transitions（展开/收起/hover 与 Windows 同时长曲线）；尝试读取系统减弱动效，不可行则如实标注仅 Windows 支持降级。以 headless 测试与 Apple Silicon CI 验证，无实机人工验收时如实标注。

## 验收

- 跨端 token 一致性测试通过（WPF 资源 == Core DesignTokens == Mac 常量），`docs/design.md` 与代码一致。
- 每个动效有锁定时长、缓动、可中断性与减弱动效降级的自动回归；快速展开/收起竞态有回归覆盖。
- 浅色与深色两种主题下各有真实截图证据（两端）；UI 变化逐阶段向用户展示截图或录屏。
- 四步质量门（格式验证、Release 全量测试、严格构建）与 Mac CI 全部通过。
