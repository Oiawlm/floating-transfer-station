# macOS 同步版本实施记录

目标：新增 Apple Silicon / Intel Mac 应用，两端共享业务和版本来源，Windows 原有行为继续通过回归。

实施范围：

- 抽取不依赖 WPF 的模型、原子保存、排序、置顶和批量变更到 `FloatingTransferStation.Core`，在 Windows 与 macOS 运行共享回归。
- 新增 Avalonia Mac 窗口，提供四分类、折叠置顶、改名、选择、批量管理、剪贴板采集和原生文件/文本拖放。Mac 快捷键使用 Command。
- 新增双架构 `.app` ZIP 打包、macOS CI 和组合质量门；沿用 `version.txt`，显式区分本机构建、Mac 实机运行与 Apple 公证。
- 执行格式检查、Release 全量测试、严格构建、真实窗口烟雾验证及双架构打包；记录存储增量和未验证项。

边界：不安装 Xcode，不购买证书，不改远端设置，不正式发布。用户于 2026-09-08 授权提交、推送功能分支并触发 Mac CI，且要求后续本仓库任务持续同步维护 Win/Mac、验证后提交推送；已记录在项目 AGENTS.md。Mac 数据在 `~/Library/Application Support/FloatingTransferStation/Data`；Windows 预览与烟雾验证使用独立数据目录。

## 本地验证结果（2026-09-08）

- Release 全量：Windows 512、共享核心 108、Mac 32 项通过；5 项 Unix 专属路径用例在 Windows 明确跳过。
- 格式验证通过；严格 Release 构建 0 警告、0 错误。WPF 格式工具首次需要预构建 Core Debug 程序集，此依赖已加入 CI/贡献说明。
- 新的 `build-release.ps1` 默认入口完整执行成功：工具契约、隔离 Inno 清理、测试、Windows 单文件安装包、两个 Mac 自包含 ZIP。
- Windows 上实际启动 Avalonia 窗口，验证文字/图片导入、选择、置顶、改名、快捷键、文本/文件拖出载荷与保存恢复；截图和完成标识在 `TestResults/macos-preview-final/`。这是 Windows 预览证据，不是 Mac 实机证据。
- 两个最终 ZIP 独立检查 CRC、Mach-O CPU 架构、Unix 执行权限、plist、运行库、版本和 SHA-256 均通过。arm64 46,900,758 字节，Intel 49,261,522 字节，合计 91.71 MiB；包旁 JSON 的 `nativeSmokeTest` 为 false、`notarized` 为 false。
- 原 Windows 安装包备份至 `artifacts/pre-macos-baseline/`。未操作已安装应用、现有用户数据、全局配置或凭据。
- 当前磁盘剩余 C 29.11 GiB、D 39.50 GiB；无需安装 Xcode 或虚拟机，临时 `.app` 已自动清理。

## 尚未验证

Mac 原生窗口/NSPasteboard、Finder 和第三方软件间拖放、下载后的 Gatekeeper 行为尚未在本机验证。CI 已配置 macOS 15 arm64 / Intel 原生测试、临时签名、包内启动及截图，将在已授权的新分支/PR 上执行。正式分发仍需要 Developer ID 签名和 Apple 公证，当前不具备这项凭据或授权。
