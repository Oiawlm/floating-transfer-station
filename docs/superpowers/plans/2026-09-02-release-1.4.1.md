# 1.4.1 Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 `Ctrl+P` 隐藏批量置顶安全修复作为 1.4.1 正式版本发布，并提供从最终合并提交构建、上传和下载回验的 Windows 安装包。

**Architecture:** 项目文件、`ProductIdentity` 与 Inno Setup 三处共同锁定 1.4.1，生命周期测试先定义版本和公共资料契约。发布准备通过 `codex/release-1.4.1` 分支和 PR 质量门进入 `main`；轻量 tag `v1.4.1` 只指向 squash 合并后的最终提交，GitHub Release 只上传在该最终提交重新构建的英文名安装包。

**Tech Stack:** .NET 10、WPF、MSTest、Inno Setup、PowerShell、GitHub CLI、GitHub Actions

- [ ] **Step 3: 快进本地 main 并等待合并后质量门**

```powershell
git switch main
git pull --ff-only origin main
git fetch --prune origin
$mainCommit = git rev-parse HEAD
if ($mainCommit -ne (git rev-parse origin/main)) { throw 'Local main does not match origin/main.' }
$qualityRun = $null
for ($attempt = 1; $attempt -le 10 -and $null -eq $qualityRun; $attempt++) {
    $qualityRuns = gh run list --repo Oiawlm/floating-transfer-station --commit $mainCommit --workflow '质量门' --limit 5 --json databaseId,status,conclusion,headSha | ConvertFrom-Json
    if ($LASTEXITCODE -ne 0) { throw 'Failed to query merged main quality gate.' }
    $qualityRun = $qualityRuns | Where-Object headSha -eq $mainCommit | Select-Object -First 1
    if ($null -eq $qualityRun -and $attempt -lt 10) { Start-Sleep -Seconds 3 }
}
if ($null -eq $qualityRun) { throw 'Merged main quality gate was not found.' }
gh run watch $qualityRun.databaseId --repo Oiawlm/floating-transfer-station --exit-status
if ($LASTEXITCODE -ne 0) { throw 'Merged main quality gate failed.' }
```

预期：PR 与合并后的 main 质量门均成功，本地 `main` 与 `origin/main` 一致且干净。

- [ ] **Step 1: 在最终 main 重建并准备英文资产**

```powershell
git fetch --prune origin
$branch = git branch --show-current
$finalCommit = git rev-parse HEAD
$remoteMain = git rev-parse origin/main
$workspaceState = @(git status --porcelain=v1 --untracked-files=all)
if ($branch -ne 'main') { throw "Expected main, found $branch." }
if ($finalCommit -ne $remoteMain) { throw 'Local main does not match origin/main.' }
if ($workspaceState.Count -ne 0) { throw 'Final release build requires a clean workspace.' }
& .\scripts\build-release.ps1
if ($LASTEXITCODE -ne 0) { throw 'Final release build failed.' }
$published = Get-Item -LiteralPath 'artifacts\publish\悬浮中转站.exe'
if ($published.VersionInfo.ProductVersion -notlike "1.4.1+$finalCommit*") {
    throw "Published ProductVersion does not identify final main commit $finalCommit."
}
$setup = Get-Item -LiteralPath 'artifacts\installer\悬浮中转站-Setup-1.4.1.exe'
if ($setup.VersionInfo.FileVersion.Trim() -ne '1.4.1') { throw 'Final installer FileVersion mismatch.' }
$releaseAsset = 'artifacts\release\FloatingTransferStation-Setup-1.4.1.exe'
New-Item -ItemType Directory -Force -Path (Split-Path -Parent $releaseAsset) | Out-Null
Copy-Item -LiteralPath $setup.FullName -Destination $releaseAsset -Force
$setupHash = (Get-FileHash -Algorithm SHA256 -LiteralPath $setup.FullName).Hash.ToLowerInvariant()
$assetHash = (Get-FileHash -Algorithm SHA256 -LiteralPath $releaseAsset).Hash.ToLowerInvariant()
if ($setupHash -ne $assetHash) { throw 'English release asset differs from final installer.' }
Get-AuthenticodeSignature -LiteralPath $setup.FullName | Select-Object Status,StatusMessage
```

- [ ] **Step 5: 下载并比对远端资产**

```powershell
$release = gh release view v1.4.1 --repo Oiawlm/floating-transfer-station --json tagName,isDraft,isPrerelease,publishedAt,url,assets | ConvertFrom-Json
if ($release.tagName -ne 'v1.4.1' -or $release.isDraft -or $release.isPrerelease) { throw 'GitHub Release state mismatch.' }
if ($release.assets.Count -ne 1 -or $release.assets[0].name -ne 'FloatingTransferStation-Setup-1.4.1.exe') {
    throw 'GitHub Release must contain exactly the expected installer asset.'

$verificationDirectory = 'artifacts\release-verification-1.4.1'

if ($LASTEXITCODE -ne 0) { throw 'Failed to download v1.4.1 installer.' }

$remoteDigest = $release.assets[0].digest -replace '^sha256:', ''

    throw 'Local asset, GitHub digest, and downloaded installer hashes differ.'
}
```

预期：1.4.1 成为正式 Latest Release，只有一个 `.exe` 资产；远端 digest、上传前本地英文资产和下载文件 SHA-256 全部一致。

## 自检

- 1.4.1 是向后兼容可靠性修复对应的最小语义版本，不覆盖 1.4.0。
- 版本、README、CHANGELOG、项目指南、安装包、tag 和 Release 均有客观检查。
- PR 必须先通过远端质量门；tag 只在 squash 合并后的最终 main 创建。
- 候选包从干净发布提交构建；最终资产必须在最终 main 重建，ProductVersion 必须包含最终提交哈希。
- 计划没有未决占位内容、无关功能或用户数据操作。
