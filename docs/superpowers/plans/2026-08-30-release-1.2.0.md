# 1.2.0 Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 `Esc` 取消选择及其异步置顶竞态保护作为 1.2.0 正式版本发布，并提供经过回验的 Windows 安装包。

**Architecture:** 项目文件、`ProductIdentity` 和 Inno Setup 三处共同锁定 1.2.0；生命周期测试先定义版本与公共资料契约。发布准备通过独立分支和 PR 质量门合并，最终 `v1.2.0` tag 指向合并后的 `main`，GitHub Release 只上传同一源码构建的英文名安装包。

**Tech Stack:** .NET 10、WPF、MSTest、Inno Setup、PowerShell、GitHub CLI、GitHub Actions

### Task 5: 发布 v1.2.0 并下载回验

**Files:**
- Create ignored: `artifacts/release/FloatingTransferStation-Setup-1.2.0.exe`
- Create ignored: `artifacts/release-notes-1.2.0.md`
- Create ignored: `artifacts/release-verification/FloatingTransferStation-Setup-1.2.0.exe`

- [ ] **Step 1: 在最终 main 重建并准备英文资产**

合并并切回干净 `main` 后重新运行权威脚本，确保可执行文件携带最终合并提交：

```powershell
& .\scripts\build-release.ps1
$finalCommit = git rev-parse HEAD
$published = Get-Item -LiteralPath 'artifacts\publish\悬浮中转站.exe'
if ($published.VersionInfo.ProductVersion -notlike "1.2.0+$finalCommit*") {
    throw "Published ProductVersion does not identify final main commit $finalCommit."
}
$setup = Get-Item -LiteralPath 'artifacts\installer\悬浮中转站-Setup-1.2.0.exe'
$setup.VersionInfo | Select-Object FileVersion,ProductVersion
Get-AuthenticodeSignature -LiteralPath $setup.FullName | Select-Object Status,StatusMessage
Get-FileHash -Algorithm SHA256 -LiteralPath $setup.FullName
Copy-Item -LiteralPath $setup.FullName -Destination 'artifacts\release\FloatingTransferStation-Setup-1.2.0.exe' -Force
Get-FileHash -Algorithm SHA256 -LiteralPath $setup.FullName,'artifacts\release\FloatingTransferStation-Setup-1.2.0.exe'
```

重新记录最终包的大小、版本、签名状态和 SHA-256；合并前候选哈希不得沿用。发布说明包含 `Esc` 取消选择、慢保存不复活旧选择、Windows 10/11 64 位和唯一安装文件名。

## 自检

- 1.2.0 是向后兼容新功能对应的最小语义版本，不覆盖 1.1.0。
- 版本、README、CHANGELOG、项目指南、安装包、tag 和 Release 均有客观检查。
- PR 必须先通过远端质量门；tag 只在合并后的最终 main 创建。
- 计划没有占位实现、无关功能或用户数据操作。
