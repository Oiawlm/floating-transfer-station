# 1.4.0 Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 `F2` 改名当前展开分类作为 1.4.0 正式版本发布，并提供从最终合并提交构建、上传和下载回验的 Windows 安装包。

**Tech Stack:** .NET 10、WPF、MSTest、Inno Setup、PowerShell、GitHub CLI、GitHub Actions

- [ ] **Step 3: 等待质量门并 squash 合并**

```powershell
gh pr checks $prNumber --watch
if ($LASTEXITCODE -ne 0) { throw 'Release PR checks failed.' }
gh pr merge $prNumber --squash --delete-branch
if ($LASTEXITCODE -ne 0) { throw 'Failed to merge release PR.' }
git switch main
if ($LASTEXITCODE -ne 0) { throw 'Failed to switch to main after merge.' }
git pull --ff-only origin main
if ($LASTEXITCODE -ne 0) { throw 'Failed to fast-forward local main.' }
$mainCommit = git rev-parse HEAD
if ($LASTEXITCODE -ne 0) { throw 'Failed to resolve merged main commit.' }
$qualityRun = $null
for ($attempt = 1; $attempt -le 10 -and $null -eq $qualityRun; $attempt++) {
    $qualityRuns = gh run list --commit $mainCommit --workflow '质量门' --limit 5 --json databaseId,status,conclusion,headSha | ConvertFrom-Json
    if ($LASTEXITCODE -ne 0) { throw 'Failed to query merged main quality gate.' }
    $qualityRun = $qualityRuns | Where-Object headSha -eq $mainCommit | Select-Object -First 1
    if ($null -eq $qualityRun -and $attempt -lt 10) { Start-Sleep -Seconds 3 }
}
if ($null -eq $qualityRun) { throw 'Merged main quality gate was not found.' }
gh run watch $qualityRun.databaseId --exit-status
if ($LASTEXITCODE -ne 0) { throw 'Merged main quality gate failed.' }
```

预期：必需的“格式、测试与构建”成功后才合并；本地 `main` 与 `origin/main` 一致且干净。继续等待合并后 main 的同一质量门成功。

- [ ] **Step 1: 在最终 main 重建并准备英文资产**

```powershell
git fetch --prune origin
if ($LASTEXITCODE -ne 0) { throw 'Failed to refresh origin before final build.' }
$branch = git branch --show-current
$finalCommit = git rev-parse HEAD
$remoteMain = git rev-parse origin/main
$workspaceState = @(git status --porcelain=v1 --untracked-files=all)
if ($branch -ne 'main') { throw "Expected main, found $branch." }
if ($finalCommit -ne $remoteMain) { throw 'Local main does not match origin/main.' }
if ($workspaceState.Count -ne 0) { throw 'Final release build requires a clean workspace.' }
& .\scripts\build-release.ps1
if ($LASTEXITCODE -ne 0) { throw 'Final release build failed.' }
$published = Get-Item -LiteralPath 'artifacts\publish\悬浮中转站.exe'
if ($published.VersionInfo.ProductVersion -notlike "1.4.0+$finalCommit*") {
    throw "Published ProductVersion does not identify final main commit $finalCommit."
}
$setup = Get-Item -LiteralPath 'artifacts\installer\悬浮中转站-Setup-1.4.0.exe'
$releaseAsset = 'artifacts\release\FloatingTransferStation-Setup-1.4.0.exe'
New-Item -ItemType Directory -Force -Path (Split-Path -Parent $releaseAsset) | Out-Null
Copy-Item -LiteralPath $setup.FullName -Destination $releaseAsset -Force
$setupHash = (Get-FileHash -Algorithm SHA256 -LiteralPath $setup.FullName).Hash.ToLowerInvariant()
$assetHash = (Get-FileHash -Algorithm SHA256 -LiteralPath $releaseAsset).Hash.ToLowerInvariant()
if ($setupHash -ne $assetHash) { throw 'English release asset differs from final installer.' }
```

重新记录最终包大小、版本、签名状态和 SHA-256；合并前候选哈希不得沿用。发布说明必须包含 `F2` 改名、双击兼容、Windows 10/11 64 位和唯一安装文件名。

- [ ] **Step 2: 创建并推送轻量 tag**

```powershell
git show-ref --verify --quiet refs/tags/v1.4.0
if ($LASTEXITCODE -eq 0) {
    if ((git rev-parse v1.4.0) -ne $finalCommit) { throw 'Existing local v1.4.0 tag points elsewhere.' }
} elseif ($LASTEXITCODE -eq 1) {
    git tag v1.4.0 $finalCommit
    if ($LASTEXITCODE -ne 0) { throw 'Failed to create local v1.4.0 tag.' }
} else {
    throw 'Failed to inspect local v1.4.0 tag.'
}
if ((git cat-file -t v1.4.0) -ne 'commit') { throw 'v1.4.0 must be lightweight.' }
if ((git rev-parse v1.4.0) -ne $finalCommit) { throw 'v1.4.0 tag mismatch.' }
git ls-remote --exit-code --tags origin refs/tags/v1.4.0 *> $null
if ($LASTEXITCODE -eq 0) {
    $remoteTagCommit = ((git ls-remote --refs origin refs/tags/v1.4.0) -split '\s+')[0]
} elseif ($LASTEXITCODE -eq 2) {
    git push origin refs/tags/v1.4.0
    if ($LASTEXITCODE -ne 0) { throw 'Failed to push v1.4.0 tag.' }
    $remoteTagCommit = ((git ls-remote --refs origin refs/tags/v1.4.0) -split '\s+')[0]
} else {
    throw 'Failed to inspect remote v1.4.0 tag.'
}
if ($LASTEXITCODE -ne 0) { throw 'Failed to resolve remote v1.4.0 tag.' }
if ($remoteTagCommit -ne $finalCommit) { throw 'Remote v1.4.0 tag mismatch.' }
```

- [ ] **Step 4: 下载并比对远端资产**

```powershell
$release = gh release view v1.4.0 --json tagName,isDraft,isPrerelease,publishedAt,url,assets | ConvertFrom-Json
if ($LASTEXITCODE -ne 0) { throw 'Failed to inspect GitHub Release v1.4.0.' }
if ($release.tagName -ne 'v1.4.0' -or $release.isDraft -or $release.isPrerelease) { throw 'GitHub Release state mismatch.' }
if ($release.assets.Count -ne 1 -or $release.assets[0].name -ne 'FloatingTransferStation-Setup-1.4.0.exe') {
    throw 'GitHub Release must contain exactly the expected installer asset.'
}
$verificationDirectory = 'artifacts\release-verification-1.4.0'
if (Test-Path -LiteralPath $verificationDirectory) { Remove-Item -LiteralPath $verificationDirectory -Recurse -Force }
New-Item -ItemType Directory -Force -Path $verificationDirectory | Out-Null
gh release download v1.4.0 --pattern 'FloatingTransferStation-Setup-1.4.0.exe' --dir $verificationDirectory
if ($LASTEXITCODE -ne 0) { throw 'Failed to download v1.4.0 installer.' }
$downloadPath = Join-Path $verificationDirectory 'FloatingTransferStation-Setup-1.4.0.exe'
$downloadHash = (Get-FileHash -Algorithm SHA256 -LiteralPath $downloadPath).Hash.ToLowerInvariant()
$remoteDigest = $release.assets[0].digest -replace '^sha256:', ''
if ($assetHash -ne $remoteDigest -or $assetHash -ne $downloadHash) {
    throw 'Local asset, GitHub digest, and downloaded installer hashes differ.'
}
```

预期：1.4.0 成为正式 Latest Release，只有一个 `.exe` 资产；远端 digest、上传前本地英文资产和下载文件 SHA-256 全部一致。
