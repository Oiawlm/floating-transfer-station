# 1.3.0 Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 `Delete` 删除选择及折叠态防误删保护作为 1.3.0 正式版本发布，并提供从最终合并提交构建、上传和下载回验的 Windows 安装包。

**Architecture:** 项目文件、`ProductIdentity` 与 Inno Setup 三处共同锁定 1.3.0，生命周期测试先定义版本和公共资料契约。发布准备通过 `codex/release-1.3.0` 分支和 PR 质量门进入 `main`；最终 `v1.3.0` 轻量 tag 指向 squash 合并后的提交，GitHub Release 只上传在该最终提交重新构建的英文名安装包。

**Tech Stack:** .NET 10、WPF、MSTest、Inno Setup、PowerShell、GitHub CLI、GitHub Actions

### Task 5: 发布 v1.3.0 并下载回验

**Files:**
- Create ignored: `artifacts/release/FloatingTransferStation-Setup-1.3.0.exe`
- Create ignored: `artifacts/release-notes-1.3.0.md`
- Create ignored: `artifacts/release-verification-1.3.0/FloatingTransferStation-Setup-1.3.0.exe`

- [ ] **Step 1: 在最终 main 重建并准备英文资产**

```powershell
git fetch --prune origin
if ($LASTEXITCODE -ne 0) { throw 'Failed to refresh origin before the final build.' }
$branch = git branch --show-current
$finalCommit = git rev-parse HEAD
$remoteMain = git rev-parse origin/main
$workspaceState = @(git status --porcelain=v1 --untracked-files=all)
if ($branch -ne 'main') { throw "Expected main, found $branch." }
if ($finalCommit -ne $remoteMain) { throw 'Local main does not match origin/main.' }
if ($workspaceState.Count -ne 0) { throw 'Final release build requires a clean workspace.' }
& .\scripts\build-release.ps1
$published = Get-Item -LiteralPath 'artifacts\publish\悬浮中转站.exe'
if ($published.VersionInfo.ProductVersion -notlike "1.3.0+$finalCommit*") {
    throw "Published ProductVersion does not identify final main commit $finalCommit."
}
$setup = Get-Item -LiteralPath 'artifacts\installer\悬浮中转站-Setup-1.3.0.exe'
$setup.VersionInfo | Select-Object FileVersion,ProductVersion
Get-AuthenticodeSignature -LiteralPath $setup.FullName | Select-Object Status,StatusMessage
Get-FileHash -Algorithm SHA256 -LiteralPath $setup.FullName
Copy-Item -LiteralPath $setup.FullName -Destination 'artifacts\release\FloatingTransferStation-Setup-1.3.0.exe' -Force
Get-FileHash -Algorithm SHA256 -LiteralPath $setup.FullName,'artifacts\release\FloatingTransferStation-Setup-1.3.0.exe'
```

重新记录最终包大小、版本、签名状态和 SHA-256；合并前候选哈希不得沿用。发布说明必须包含 `Delete` 快捷键、折叠态防误删、Windows 10/11 64 位和唯一安装文件名。

- [ ] **Step 2: 创建并推送轻量 tag**

```powershell
$existingTag = git show-ref --verify --hash refs/tags/v1.3.0
if ($LASTEXITCODE -eq 0) {
    if ($existingTag -ne $finalCommit) { throw 'Existing local v1.3.0 tag points elsewhere.' }
} else {
    git tag v1.3.0 $finalCommit
}
if ((git rev-parse v1.3.0) -ne $finalCommit) { throw 'v1.3.0 tag mismatch.' }
git push origin refs/tags/v1.3.0
if ($LASTEXITCODE -ne 0) { throw 'Failed to push v1.3.0.' }
$remoteTagLine = git ls-remote --refs origin refs/tags/v1.3.0
if ($LASTEXITCODE -ne 0 -or [string]::IsNullOrWhiteSpace($remoteTagLine)) {
    throw 'Remote v1.3.0 tag is unavailable after push.'
}
$remoteTagCommit = ($remoteTagLine -split '\s+')[0]
if ($remoteTagCommit -ne $finalCommit) { throw 'Remote v1.3.0 tag mismatch.' }
git cat-file -t v1.3.0
git rev-parse v1.3.0
```

预期：tag 类型为 `commit`，与最终 `main` 完全同一提交。

## 自检

- 1.3.0 是向后兼容新功能对应的最小语义版本，不覆盖 1.2.0。
- 版本、README、CHANGELOG、项目指南、安装包、tag 和 Release 均有客观检查。
- PR 必须先通过远端质量门；tag 只在 squash 合并后的最终 main 创建。
- 最终资产必须在最终 main 重建，ProductVersion 必须包含最终提交哈希。
- 计划没有待填内容、无关功能或用户数据操作。
