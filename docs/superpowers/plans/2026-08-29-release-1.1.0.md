# 1.1.0 Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把批量置顶与 `Ctrl+A` 全选作为 1.1.0 正式版本打包，通过受保护 PR 合并到 `main`，并发布可验证的 Windows 安装包。

**Architecture:** 版本号由项目文件、`ProductIdentity` 和 Inno Setup 三处共同锁定，生命周期测试先定义 1.1.0 契约。发布分支通过 PR 质量门后合并；轻量 tag `v1.1.0` 指向最终 `main` 提交，GitHub Release 只上传从相同源码内容生成的英文名安装包。

**Tech Stack:** .NET 10、WPF、MSTest、Inno Setup、PowerShell、GitHub CLI、GitHub Actions。
